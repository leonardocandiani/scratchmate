## What's new in 0.1.0

The first public release of ScratchMate.

- Ephemeral note deck: a floating window on a global hotkey that hides on blur and saves itself.
- Command palette (`::` or Cmd K) with native text commands: date, UUID, JSON, sort, dedupe, case, comment, wrap, code block, export.
- Find across all notes with Cmd F.
- Live preview (Cmd R) for markdown, JSON and code.
- Eight themes, plus a light and dark pair that follows the system appearance.
- Liquid Glass material on macOS 26, with a graceful fallback below it.
- Local first: notes live in SQLite, with no account and no cloud.
